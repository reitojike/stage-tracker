## 色と形の語彙

| 用途 | 値 |
| --- | --- |
| 紙 | `#eef0f1` |
| 細罫 | `#d7dcde` |
| 淡い面 | `#dfe4e7` （`--color-surface-subtle`） |
| 藍（操作・現在地） | `#2f4a7a` |
| 藍の淡い面（完了・帯） | 面 `#dbe2ee` / 文字 `#24365c` |

| コントロールの罫 | `#7f878b` |

角丸は3値のみ。**2px = バッジとボタン**、**4px = 入力欄・枠・淡い面**、**6px = 画面の外枠**。
白面のカードは使いません（`background: #ffffff` + `radius: 12px` の組み合わせは誤り）。
赤は期限専用です。エラー表示には使いません。
