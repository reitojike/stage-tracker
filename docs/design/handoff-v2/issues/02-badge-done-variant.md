# 2. Badge に「完了」variant

## 背景

「申し込む予定」と「申し込み済み」が同じ淡い面で、行のいちばん重要な状態が見分けられない。また参加状態（参加する / 気になる）だけが「淡い面＋枠線」という第5の形になっていて、outline＝カテゴリ / subtle＝進行中 のどちらでもない。

参照: TURN 15（15d / 15e / 15f の比較、採用は 15f）、TURN 14a

## 変更

`src/ui/Badge.tsx` / `Badge.module.css`

- variant を 4 → 5 に。新規 `done`
  - 面 `#dbe2ee` / 文字 `#24365c`
  - ラベルの前に ✓ を置く（コンポーネント側で付ける。呼び出し側の文字列に ✓ を含めない）
  - この2色はカレンダーの帯で既に使っている値。新しい色は増えない
- `subtle` から枠線を出す使い方を禁止する。参加状態が `border: 1px solid #454b4e` を足していたのを廃止

## 適用箇所（各画面Issueで実施、ここでは variant の追加まで）

| 文言 | variant |
| --- | --- |
| 参加する / 気になる | subtle |
| 申し込む予定 | subtle |
| 申し込み済み | **done** |
| チケット確保済み | **done** |
| 自分の予定 / 共有されている予定 | subtle |
| ジャンル / 下位 | outline |
| 残りN日・本日 23:59まで | deadline |
| 中止 / 受付終了 | terminal |

## 確認

- `#dbe2ee` の上の `#24365c` は 4.5:1 以上
- 12e で「申し込む予定」と「✓ 申し込み済み」が隣り合っても区別できる
