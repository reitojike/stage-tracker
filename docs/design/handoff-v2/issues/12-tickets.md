## 背景

1件あたりの縦幅が広すぎる（約230px）。行がリンクになっておらず、他の画面と語彙が違う。「申込締切」バッジ・日付・「残り1日」で同じことを3回言っている。

参照: TURN 14a

## 変更

`src/app/tickets/_components/TicketOpportunityRow.tsx` ほか

### 日付カラム（幅 7.1em）

上から順に:

1. マイルストーン名 — 14px 600 `#5c6467`（申込締切 / 結果発表 / 販売開始）
2. 日付 — 16px 600、色は #5 の規則、曜日は全角カッコで 14px 400
3. 時刻 — 14px `#5c6467`（無ければ出さない）
4. 残り日数バッジ — #7 の規則（該当するときだけ）

左カラムだけで「いつ何が起きるか」が完結する。**バッジ列からマイルストーン名を外す**。

### 本文カラム

1. 状態バッジ **1つだけ**（申し込む予定 / ✓ 申し込み済み / 中止 / 受付終了）
2. 演目名 — 16px 600
3. 券種・会場 — 14px `#5c6467`、`・` 区切りの1行
4. 対象公演回 — 14px `#5c6467`。**公演全体のものには出さない**。対象公演回があるものだけ「対象公演回: 9月13日（日）18:00、9月14日（月）13:00」
5. 操作 — quiet ボタン（#1 で淡い面が付く）

### 行のリンク化

- 行全体を演目詳細へのリンクにし、右端に `›`（16px `#737b82`、垂直中央）
- リンクの中に quiet ボタンを入れ子にしない。リンクを行いっぱいに広げた擬似要素にして、ボタンを前面（`position: relative`）に置く
- ボタンを押したときにリンクが発火しないこと

### 一覧に残す期間

#8 の規則。
