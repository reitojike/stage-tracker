# 8. 表示範囲（保持期間と窓）

## 背景

締切が過ぎたチケットが過去月に積もり続ける。ホームの直近の予定が何日先まで出るかも決まっていない。

参照: TURN 12 左パネル「決めごと」

## 規則

### チケット

- 次のマイルストーンが残っている限り出す（申込締切 → 結果発表 → 入金期限）
- 最後のマイルストーンも過ぎたものは、その日から **7日** だけ残す。状態は「受付終了」等の terminal
- 7日を過ぎたら一覧から落とす。イベント詳細からは引き続き辿れる
- 月の見出しは、その月に出す行が無くなった時点で消える

### ホーム

- 直近の予定: 今日から **14日先** まで、最大 **5件**
- 14日以内に1件も無いときは、次の1件だけを日付付きで出す（空セクションにしない）
- 申し込み期限: 同じく14日以内。件数の上限は設けず横に流す。全件は「すべて見る」からチケット画面へ

## 変更

`src/domain/homeDeadlines.ts` と、チケット一覧の読み取り側（`src/app/tickets/page.tsx` が使う選択関数）。窓の値は定数として1か所に置く。

## 確認

- 締切から8日経った Opportunity がチケット一覧に出ない
- 15日先の予定がホームに出ない。ただし14日以内が0件なら1件だけ出る
