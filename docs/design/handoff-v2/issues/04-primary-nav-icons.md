# 4. PrimaryNav にアイコン

## 背景

文字のみの4項目で「マイカレンダー」だけが2行に折り返し、高さが揃わない。

参照: TURN 14d（A / B / C の比較、採用は B）、TURN 12 全画面

## 変更

`src/ui/PrimaryNav.tsx` / `PrimaryNav.module.css`

- 各項目を アイコン（21px）＋ラベル の縦積みに
- ラベル 12px → **11px**、アイコンとの gap 3px
- 項目の `min-height` 56px → **60px**（`box-sizing` が content-box で padding 4px が乗るため実測は 68px）
- ラベルは4項目とも元の文字列のまま。「マイカレンダー」の2行折り返しは許容し、4項目の高さを揃える
- 現在地の藍の上帯（`top: 0; left/right: 12px; height: 2px`）はそのまま
- アイコンは `stroke="currentColor"` の 24×24 viewBox。現在地 `#1f2426` / 非現在地 `#5c6467` は既存のラベル色をそのまま継ぐ

## アイコン

| 項目 | 形 |
| --- | --- |
| ホーム | 屋根＋箱 |
| イベント | カレンダー |
| チケット | 半券（両側にくびれ） |
| マイカレンダー | カレンダー＋チェック |

イベントとマイカレンダーは同じカレンダーなので、チェックの有無で区別する。

## 確認

- 4項目の高さが揃う
- タップ範囲は各項目 60px 以上
