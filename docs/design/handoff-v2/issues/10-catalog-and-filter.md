# 10. イベント ＋ 絞り込みシート

参照: **12b**（一覧）、**12c**（シート）、**12g**（0件）

前提: #1〜#8

## イベント画面

`src/app/catalog/page.tsx` / `_components/CatalogView.tsx`

- **ActionRow を撤去**。「+ 追加」「招待一覧」はマイページへ移す（#13）。タイトル直下からカレンダーが始まる
- 絞り込み中だけ、見出しの下に条件の行を出す
  - 高さ 44px、上下に細罫 `1px solid #d7dcde`、面は敷かない
  - 文言 `絞り込み中: **宝塚** / 花組・雪組`（ジャンルを 600、下位を通常）
  - 右端に ✕（30px、`#5c6467`）。押すと全解除
  - 絞り込んでいないときは行ごと出さない（高さも取らない）
- カレンダーに **今日** のマーカーを追加。マイカレンダーと同じ、日付を `22px` の丸 `#c3c9ce` で囲む。選択枠（`inset 0 0 0 1.5px #1f2426`、角丸4px）とは別
- 選択日リストのバッジを **「ジャンル / 下位」** 表記に。下位はジャンルごとに意味が変わる（アイドル→グループ、宝塚→組、歌舞伎→会場）。下位が無い場合はジャンルのみ
- 0件・エラーは #3

## 絞り込みシート

`src/app/catalog/_components/FilterSheet.tsx` / `_lib/catalogFilterData.ts`

- ジャンルを縦のラジオから **横並びのチップ** に。単一選択という判断は変えない
  - 各チップ `flex: 1 1 76px`、`min-height: 44px`、角丸4px
  - 選択中は面 `#2f4a7a` / 文字 `#ffffff` / 600、非選択は `transparent` ＋ 罫 `#b9bfc4` / 文字 `#454b4e`
  - **折り返す**（横スクロールにしない）。単一選択は全候補が見えていないと選べない
  - ジャンルが10件を超えたらチップをやめてドロップダウンに切り替える
- 下位facet（組・会場など）は三状態チェックボックスのまま。見出しに「（複数選べます）」を添えて、上の単一選択との違いを言葉でも示す
- フッターに **「条件をクリア」**（quiet）を追加。「この条件で絞り込む」は藍のまま、角丸4px
- シートの面は白 `#ffffff` → **紙 `#eef0f1`** に。他の画面と同じ地色にする
