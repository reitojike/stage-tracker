# 7. 残り日数の閾値

## 背景

「残りN日」が赤か輪郭かの切り替え点が決まっていない。9日前から赤だと、本当に迫っているものと区別が付かない。

参照: 12a、12e、TURN 12 左パネル「決めごと」

## 規則

| 状況 | バッジ | 文言 |
| --- | --- | --- |
| 締切当日 | deadline（赤） | 本日 23:59まで（時刻は実データ） |
| 残り1〜3日 | deadline（赤） | 残りN日 |
| 残り4〜13日 | outline（輪郭） | 残りN日 |
| 残り14日以上 | 出さない | — |
| 締切後 | terminal（墨） | 受付終了 |

赤は「今日か明日動かないと間に合わない」に限定する。14日より先は日付だけで足りる。

## 変更

`src/domain/ticketOpportunityFormatting.ts` に判定を1つ置き、ホーム（`src/domain/homeDeadlines.ts`）とチケット画面の両方がそれを使う。画面側で閾値を持たない。

境界は Asia/Tokyo の暦日で数える（`tokyoCalendarDateFromInstant` と同じ基準）。時刻の差ではなく日付の差。

## 確認

- 締切が今日 23:59 のものが「残り0日」ではなく「本日 23:59まで」になる
- 14日以上先のものにバッジが出ない
