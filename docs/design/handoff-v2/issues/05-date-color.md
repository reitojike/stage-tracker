# 5. 日付色の共通化

## 背景

カレンダーのセルは日曜・祝日が赤、土曜が藍になっているが、リストの日付見出しは全部 `#1f2426` のまま。同じ日付なのに画面によって色が違う。

参照: 12a（8月30日（日）が赤）、12b・12d・12e

## 変更

日付文字列を色付きで出す共通の仕組みを1か所に置く（`src/domain/calendarMonth.ts` の隣か、`src/ui/` の小さなコンポーネント）。祝日判定は `buildMyCalendarDayMarkers` が使っている既存のスナップショットを流用し、新しいデータ源を作らない。

| 曜日 | 色 |
| --- | --- |
| 日曜・祝日 | `#a13b2e` |
| 土曜 | `#2f4a7a` |
| その他 | `#1f2426` |

適用先:

- ホームの直近の予定の日付見出し（12a）
- イベントの選択日見出し（12b）
- マイカレンダーの選択日見出し（12d）
- チケットの日付カラム（12e）— 月見出し「2026年8月」には付けない

## 曜日の表記

**全角カッコに統一**する: `8月30日（日）`。チケットの日付カラムは全角化で幅が足りなくなるので **7.1em** に広げる。

## 確認

- 4画面すべてで同じ日付が同じ色
- 祝日カバレッジ外の日は従来どおり「未確定」の扱いのままで、赤にしない
