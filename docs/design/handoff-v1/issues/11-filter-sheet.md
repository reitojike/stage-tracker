# 絞り込みシートを新設する

**labels**: screen, new
**depends on**: #3 tristate checkbox

## やること

参照: `screens/10e-filter-sheet.png`、設計HTMLの id `10e`

- `/catalog` のフィルターアイコンから、画面下から出るシートを開く
- 上端のみ角丸4px、境界は1px `--color-border`、背後は暗幕。出入りは200ms程度の ease-out
- 行は ラベル + チェック（#3 の三状態）+ ★（お気に入り）。行の高さは44px以上
- **中間層（例: 宝塚）は部分選択の三状態を持つ**
- **お気に入りは中間層と最下層の両方に付けられる**
- **件数は表示しない**
- 下部に確定ボタン1つ（この画面の塗りボタンはこれだけ）
- 確定した条件を永続化し、次回の `/catalog` で復元する

## 完了条件

- 中間層をタップすると配下が一括で切り替わり、配下を個別に変えると中間層が部分選択になる
- 閉じて開き直しても状態が保たれる
