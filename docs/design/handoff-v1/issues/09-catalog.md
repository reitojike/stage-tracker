# イベント（/catalog）を確定版の表示規則に更新

**labels**: screen
**depends on**: #2 badge, #6 calendar

## やること

参照: `screens/10b-catalog.png`、設計HTMLの id `10b`

- カレンダーは #6 の marker 規則に従う（件数Badge廃止、dot 1個、帯にカテゴリ短縮ラベル）
- **絞り込みは ActionRow のボタンをやめ、ページ見出し行の右端のフィルターアイコン（40×40）にする。** 絞り込み中はアイコン右上に `--color-accent` の点
- 選択日リスト: 日付見出し（太罫 15px/600）+ 行（時刻列44px + 本文）。区切りは1px細罫
- 行のバッジは 分類 = `outline`、状態 = `subtle` / `terminal`
- 月移動は `‹ 2026年9月 ›`（両端40×40）
- 曜日ヘッダは11px/600。土 = 藍、日 = 赤、他 = `--color-text-secondary`
- **既定表示は前回の絞り込み状態を復元する**
- カード面（`Surface`）は使わない

## 完了条件

- 絞り込み中かどうかが、シートを開かずに分かる
- 「受付終了」の公演が墨のバッジで表示される
