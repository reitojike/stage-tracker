# 03. イベントの登録・編集画面

参照画像：`../reference/event-create-390.png` / `../reference/event-edit-390.png`
デッキ：TURN 23b（編集）/ 23c（登録）、シートの中身は TURN 22
前提：01

対象：`/catalog/events/new`、`/catalog/events/[eventId]/edit`

## 背景

どちらも白い `Surface` と `ActionRow` のまま、TURN 12 の語彙が当たっていません。
編集画面は公演回ごとの3項目がインラインに展開し、送信ボタンが6つ並びます。
登録画面は9項目のうち7項目に `helperText` が付き、フォームの半分が説明文です。

## 1. 面を外す

白い `Surface`（角丸12px）をやめ、1px 細罫（行）と 2px 太罫（見出し）に置き換えます。
`ActionRow` の枠付きボタンは、見出し行の右の quiet に。

## 2. 編集画面：公演回を行に畳んでシートへ

現行は公演回1件ごとに開場・開演・終演の3入力が展開しています。これを
**1件1行のリスト**にし、右の quiet「変更」でシートを開きます。追加も同じシート語彙。

- 行に置くのは日時と、中止なら中止 badge。右に quiet「変更」
- シートの見出しは公演回の日時。中身は開場・開演・終演の3入力と保存
- **1件だけを扱うシートなので、その1件の中止・削除はシートの中に置く**
  （保存の下に細罫を挟んで「この公演回を中止」「この公演回を削除」）
- 理由は誤タップ。リストの行に赤い操作を並べると隣の行を狙ったタップが削除に当たる

## 3. 送信ボタンを整理する

現行は6つ（塗り3・赤2・細枠2）が本文に並んでいます。塗りは1画面1つの規則に合わせます。

| 置く場所 | ボタン |
|---|---|
| 画面下の固定帯（右寄せ） | イベント情報を保存（塗り） |
| 開催期間の見出し右 | quiet「変更」→ シート内に 開催期間を保存（塗り） |
| 公演回の行 | quiet「変更」→ シート内に この公演回を保存（塗り） |
| 最下部の赤い見出しの下 | このイベントを中止（細枠）/ このイベントを削除（赤枠） |

**文言は実装のまま変えません。** イベント情報を保存 / 開催期間を保存 /
この公演回を保存 / 公演回を追加 / この公演回を中止 / この公演回を削除 /
このイベントを中止 / このイベントを削除。

## 4. 補足テキストを減らす（登録画面）

- ラベルで分かることは書かない（「開催期間（開始日）」→「初日」にすれば
  「公式に公表されている初日です」は不要）
- 同じ話は1か所に。「日本時間（Asia/Tokyo）」は各フィールドではなくグループの末尾に1行
- **空欄の扱いは残す。** 「未入力の場合は未公表として扱われます」
  「未定の場合は空欄のままにできます」は挙動の説明なので削らない

## 5. 送信は画面下に固定

`--color-canvas` の面に上細罫を引いた 12/16px の帯を画面下に固定し、右寄せで置きます。
長いフォームで、送信がスクロールしないと押せない状態を避けるためです。

## 6. 日付は横並び

開始と終了の対になる日付は2列。開催期間（初日・千秋楽）がこれにあたります。
開場・開演・終演は3つで対ではないので縦のまま。

## 7. 任意のグループは淡い面に沈める（登録画面）

「初回公演回」は任意。淡い面 `#dfe4e7`・角丸4px・padding 14px でくくり、
見出しの右に「任意」を12pxで置きます。必須の2グループと区別が付きます。

## 触らないもの

- フィールドの構成、`name`、バリデーション文言、必須の印（`RequirementIndicator`）
- 入力の寸法（min-height 44px / 角丸4px / 境界 `#7f878b`）
- 送信ボタンの文言
- URL、権限（オーナーのみ編集可）、write action の redirect 先

- [ ] 白い `Surface` が1つも残っていない

- [ ] 公演回が1件1行になり、変更でシートが開く
- [ ] 公演回の中止・削除がシートの中にある
- [ ] イベント全体の中止・削除が最下部の赤い見出しの下にある
- [ ] 登録画面の補足が7本から3本以下
- [ ] 送信ボタンがスクロール位置によらず押せる
- [ ] 送信ボタンの文言が実装と一致している
- [ ] 390px で参照画像との重大な visual 差異がない
