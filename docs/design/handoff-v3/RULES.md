## 角丸 — 箱の大きさで2値

| 値 | 箱の大きさ | 該当 |
|---|---|---|
| 2px | 18〜20px の小さな箱と印 | バッジ、カレンダーの帯、チェックボックスの箱（18px） |
| 4px | 31〜44px の箱 | ボタン、ジャンルのチップ、入力欄、シートの上端、カレンダーのセル |

役割（「触れるもの」など）ではなく大きさで分けます。同じ radius でも箱が大きいほど
丸みの印象は弱くなるため、この2値のほうが揃って見えます。チェックボックスの
タップ範囲は箱ではなく 44px の行全体なので、44px ルールとも矛盾しません。

**白面のカードは使いません。** `Surface`（白・角丸12px）は残 Issue 04 / 05 の画面が
最後の利用者で、それが済めば利用者が0になります。

モックの390px の外枠に使っている 6px は作図上の値で、アプリ側には存在しません。

### quiet の例外

**行全体がリンクになっている行の中だけ、静止時に淡い面（`#dfe4e7`）を許します。**
該当はチケット行の状態変更のみ。理由は「行全体がリンクなので、押せる場所が
どこかを示す必要がある」ことで、quiet だからではありません。

## シート

- 覆い `rgba(23, 25, 27, 0.45)`、面 `#eef0f1`、上端の角丸 4px、`max-height: 85vh`
- 見出し 16px/600、下に 1px 細罫
- **footer を持つシートはヘッダに「閉じる」を出さない。持たないシートは出す**
  （footer がないシートでは、閉じるが画面に見えている唯一の離脱手段）
- 覆いのタップと Escape はどちらでも効く
- 藍の塗りはシート内の実行ボタン1つだけ

## バッジ — 5段階

| 形 | 意味 | 例 |

| 輪郭 | カテゴリ | 宝塚 / 花組 |

| 淡い面（藍）＋✓ | 自分が終えたこと | ✓ 申し込み済み |

共通サイズは padding 3px 8px、角丸 2px、11px/600/1.4。

## 破壊的操作の置き場所

- 原則：本文の最下部に、赤の見出し＋2px 太罫で隔離する
- 例外：**シートが1件だけを扱っている場合、その1件の中止・削除はシートの中に置く**
  （公演回のシートがこれにあたる。リストの行に赤を並べると誤タップの危険がある）
- イベント全体の中止・削除は編集画面の最下部のまま
- 確認（PO 確定 2026-09-01・同日の前案を撤回）：**元に戻せるかで2つに分ける**
  - **削除（元に戻せない3件：イベント / 公演回 / 個人予定）** — 自作の確認シート。`Sheet` を使い、
    タイトルはその操作名、本文は現行の `CONFIRM_MESSAGE` そのまま、footer に `danger` の実行ボタン、
    ヘッダに「閉じる」は出さない。覆いのタップと Escape が取り消しに当たる
  - **中止・解除（元に戻せる2件）** — 確認を出さない。押した時点で実行し、結果は通知で伝える
  - native `window.confirm()` は使わない

## 書き込みのフィードバック

- 通知は、その書き込みを起こしたまとまり（フォーム全体、またはシート1枚）の**先頭**に出す。
  ボタンの隣には置かない — 横並びのボタン行に入れると行が崩れる（Issue 06 の4件目）
- 通知の見た目：淡い面 `#dfe4e7`、角丸 4px、13px。live region は常時マウントし、
  メッセージ側を試行回数でキーする（同じ文言の2回目を読み上げさせるため）
- 処理中の語は、その操作の動詞をそのまま「〜中…」にする。送信ボタンのラベルから機械的に作る
  （「予定を保存」→「保存中…」）。「処理中…」は動詞が特定できない場合だけ

## 読み込み中の見せ方（PO 確定 2026-08-31）

2系統を意図的に使い分けます。

- **skeleton** — レイアウトが先に決まっている画面（カレンダー）。枠組みを先に出して跳ねを防ぐ
- **spinner** — 中身の量でレイアウトが変わる画面（`loading.tsx` の各ルート）。
  `LoadingIndicator` の `md`、インラインは `sm`

迷ったら spinner。skeleton は「実物と同じ骨組みが描ける」ときだけ。

## 一時的に操作できる行（取り消し行）

書き込み通知とは**別語彙**です（PO 確定 2026-08-31）。

- 通知＝「終わったこと」の控え。淡い面のテキストのみ
- 取り消し行＝「まだ操作できる」。淡い面 44px の行＋右に下線付きのテキスト操作
  （招待一覧の8秒の「取り消す」がこれ）

見た目が似ているため、取り消し行には必ず操作（下線付きのテキスト）を1つ置いて区別します。
